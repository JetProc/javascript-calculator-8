# javascript-calculator-precourse

## 프로그램 큰 흐름

1. 문자열 입력 받기
2. 문자열에 커스텀 구분자가 존재한다면 찾기
3. 구분자(커스텀 구분자 포함)로 구분하여 숫자 배열 만들기
4. 숫자 배열의 값을 모두 더하기
5. 결과 출력하기

## 구현할 기능 목록

### 1. 문자열 입력 받기

1. 시작 문구 출력 및 문자열 입력
   1. 문구 : `덧셈할 문자열을 입력해 주세요.`
   2. 함수 : Console.readLineAsync()

### 2. 문자열에 커스텀 구분자가 존재한다면 찾기

1. 정규표현식을 이용하여 커스텀 구분자 여부 찾기
   1. 커스텀 구분자가 있는 경우
      1. 커스텀 구분자를 구분자 리스트에 추가하기
      2. \n 앞부분을 잘라내기

### 3. 구분자(커스텀 구분자 포함)로 구분하여 숫자 배열 만들기

1. 만들어진 숫자 배열의 숫자들을 Number형으로 변환하기

### 4. 숫자 배열의 값을 모두 더하기

1. 함수 : arr.reduce 사용

### 5. 결과 출력하기

1. 문구 : `결과 : ${sum}`
2. 함수 : Console.print()

## 예외 처리

### 입력 문자열 예외처리

1. 입력 문자열이 없다면 0 출력
2. 입력 문자열에 구분자가 없다면 ERROR

### 자료형 예외처리

1. 구분자로 구분된 값에 문자가 있다면 ERROR
2. 구분자로 구분된 값에 양수가 아닌 숫자가 있다면 ERROR

### 구분자 예외처리

1. 커스텀 구분자에 아무것도 없다면 ERROR
2. 커스텀 구분자가 문자가 아니라면 ERROR
3. 커스텀 구분자가 공백이라면 ERROR
4. 커스텀 구분자의 여는 태그만 있을 경우 ERROR
5. 커스텀 구분자의 닫는 태그만 있을 경우 ERROR
